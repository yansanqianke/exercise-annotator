# 课程设计任务书

## 技术路线

| 模块 | 技术 |
|------|------|
| 前端 | Vue3 + Element Plus |
| 后端 | Python + FastAPI |
| 数据库 | SQLite |
| 向量数据库 | Chroma（或 Milvus） |
| 大模型 | OpenAI / Qwen / DeepSeek API（任选） |
| 文档解析 | PDF、PPT、Word 解析 |
| RAG | LangChain / LlamaIndex（任选） |

---

## 开发要求

完成一个独立 Web 系统。

### 1. 基础功能

#### 用户管理
- 用户注册
- 用户登录
- JWT 身份认证
- 用户信息管理

#### 系统管理
- Web 系统首页
- 大模型配置页面
- 智能体管理页面
- 系统调用历史及日志

#### 智能体相关
- 大模型对话页面
- 智能体介绍页面
- 智能体调用页面

### 2. 接口协议
- 管理相关接口统一使用 HTTPS 进行消息传递，可采用 GET、POST 等各种模式
- 大模型及智能体调用相关接口统一使用 SSE 等方式，要求实现流式传输

### 3. 统一部署

每个项目均应提供以下代码：
- 前端
- 后端
- README
- 数据初始化脚本
- Dockerfile / Docker Compose 配置文件

部署时需支持 Docker 一键部署。

## 需实现的系统

### 习题知识点标注智能体

#### 建设目标

建立习题与知识点之间的关联。

#### 输入

支持以下题型：
- 选择题
- 判断题
- 简答题
- 编程题

#### 功能

自动完成：
- 知识点标注
- 难度标注
- 题型标注

#### 输出示例

```
题目 001
  DS-KP-006
  DS-KP-007
```
